# Operator Guide

1. Capture or upload a plate image with the whole plate in frame.
2. Wait for automatic detection to complete.
3. Review each detected disc:
   - confirm or change the antibiotic code
   - inspect warnings
   - adjust the diameter with the slider or numeric field if needed
4. Save the review and open the final table.
5. Use the CSV export endpoint when a spreadsheet export is required.

## Good Capture Practice
- Avoid glare and strong reflections.
- Keep the plate centered.
- Retake blurred images.
- Make sure disc labels are readable before analyzing.
